# Engine Catalogue
## Purpose
Define named future analysis responsibilities.
## Scope
Architecture catalogue; no engine behavior is implemented.
## Main Content
Input/context: data, market-context, market-structure, multi-timeframe, correlation. Deterministic evidence: trend, support-resistance, supply-demand, liquidity, volume, momentum, volatility, pattern-recognition, candlestick. Aggregation/finalization: confluence, opportunity-filter, evidence, decision, risk, validation, confidence, explainability, AI layer. Evaluation/future: backtesting and strategy layer.

Every engine requires attributable inputs, instrument/timeframe/timestamp provenance, explicit status, warnings/errors, validation, and non-silent failure. Exact algorithms, data requirements, weights, and provider choices are Decision Required.
