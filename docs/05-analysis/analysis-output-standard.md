# Analysis Output Standard
## Purpose
Set traceability requirements for engine outputs.
## Scope
Future engine contracts.
## Main Content
Outputs must identify engine and version, status, input provenance, instrument, timeframe, timestamp, findings, evidence, warnings, and errors. Confidence contribution is optional and must not imply a probability. Exact field schema is Decision Required.
