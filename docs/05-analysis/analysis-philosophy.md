# Analysis Philosophy
## Purpose
Define the non-negotiable analysis boundary.
## Scope
Future analysis architecture only.
## Main Content
The platform is not an indicator aggregation system. Market data flows through normalization, context, deterministic engines, evidence, confluence, decision, risk, confidence, validation, and only then AI explanation. Indicators are evidence tools, never automatic decision authority. AI cannot fabricate data/evidence, override validated deterministic results, bypass validation, or conceal uncertainty.
