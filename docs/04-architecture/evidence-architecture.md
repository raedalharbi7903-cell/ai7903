# Evidence Architecture
## Purpose
Define structured evidence requirements.
## Scope
Future deterministic analysis outputs.
## Main Content
Evidence is attributable output supporting later confluence and decision work. It requires source engine, provenance, instrument, timeframe, timestamp, freshness, reliability context, direction where applicable, relationships, and validity status. Duplicate, invalid, missing, and conflicting evidence must remain explicit. Numerical strength/weighting is Decision Required.
