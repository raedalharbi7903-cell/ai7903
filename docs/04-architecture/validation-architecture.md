# Validation Architecture
## Purpose
Define validation before user-facing delivery.
## Scope
Future analysis flow.
## Main Content
Validate inputs, freshness, engine outputs, evidence, consistency, decisions, confidence, and final output. Failed validation must produce explicit failure, degraded analysis, partial analysis, or no-decision; exact policy is Decision Required.
