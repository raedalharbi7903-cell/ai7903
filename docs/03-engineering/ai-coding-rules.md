# AI Coding Rules
## Purpose
Govern Codex and other AI coding agents.
## Scope
All AI-assisted repository work.
## Main Content
Stay within task scope; preserve architecture; do not invent requirements; avoid unrelated files; do not change public contracts without approval. Validate work, fix root causes, report autonomous decisions, preserve compatibility, prefer simple maintainable solutions, never hide failures, and never claim unverified results. Follow the Approval Policy and stop for CTO decisions.
