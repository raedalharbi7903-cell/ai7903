# Definition of Done
## Purpose
Define completion criteria for a sprint or change.
## Scope
All implementation and documentation work.
## Main Content
Done requires scoped implementation, applicable tests, lint, formatting, build, security validation, documentation, review readiness, clean intended Git status, and required environment validation. Report known limitations. A software failure is a reproducible project defect and must be fixed. An environmental blocker is an external unavailable dependency or service and must be evidenced, reported, and never misrepresented as a passing check.
